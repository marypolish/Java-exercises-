Ця програма генерує масив із 50 випадкових чисел у заданому користувачем діапазоні, після чого обчислює добуток кожної пари сусідніх чисел (парний-непарний) у масиві,
розподіляючи обчислення між потоками для пришвидшення роботи. Результати з кожного потоку збираються в один список,
і програма виводить його на екран разом із часом, витраченим на виконання.
