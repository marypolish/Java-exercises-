Завдання 1: Пошук елемента в двовимірному масиві
Work Stealing (Fork/Join Framework):
Використано для поділу масиву на частини (рядки) з динамічним розподілом задач. Це зменшує затримки, якщо одна частина виконується довше.

Work Dealing (Executor Service):
Використано для фіксованого розподілу завдань між потоками. Підхід ефективний, коли кількість задач відома наперед (один потік обробляє один рядок).

Порівняння:
Work Stealing краще адаптується до нерівномірного навантаження, але складніший в реалізації. Work Dealing простіший, але менш гнучкий.

Завдання 2: Пошук зображень у директорії
Work Stealing (Fork/Join Framework):
Обрано для роботи з вкладеними директоріями, оскільки задачі створюються та виконуються рекурсивно. Динамічний розподіл навантаження робить підхід ефективним.
Чому не Work Dealing?
Фіксований розподіл задач у Work Dealing менш підходить для задач із непередбачуваною структурою, як-от пошук у вкладених директоріях.
